# Sparse image restoration (SIR)

## Description

This folder contains MATLAB implementations and numerical experiments for sparse image restoration using proximal gradient methods and CROP-PG acceleration.

## Requirements

- MATLAB
- No additional toolboxes are required unless specified by the scripts.

## How to Run

1. Download or clone the repository.
2. Open MATLAB and navigate to the `NRR_GITHUB` directory.
3. Run the main experiment script provided in this folder.

## Methods

The experiments compare proximal gradient methods with acceleration techniques, including CROP-PG.

## Reproducibility

Experimental parameters and data generation settings are specified in the MATLAB scripts.
